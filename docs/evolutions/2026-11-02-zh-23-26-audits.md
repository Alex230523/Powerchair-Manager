# 23 et 26. Audits automatiques : affichage et droits (02/11/2026)

Deux audits tournent dans la CI (tâche « Audits (display and rights) ») sur le club et la fédération de démo, un deuxième club et une deuxième fédération.

## 26. Matrice des droits (`npm run audit:access`)

- Chaque route d'API est appelée pour de vrai par chaque rôle : anonyme, président, coach, joueur, parent, fédération, arbitre, travailleur fédéral, président du deuxième club, président de la deuxième fédération.
- `tests/access-matrix.ts` porte maintenant, pour chaque route et chaque rôle, le statut attendu (200, 401, 403, 404 ou 400), relevé lors d'un premier passage puis relu : les vues renvoient à chacun ses propres données, les écritures au corps vide sont refusées pour tous.
- Le test échoue si un statut change, si une lecture montre les données de l'autre club ou de l'autre fédération, ou si une écriture vide est acceptée.
- `docs/MATRICE-DROITS.md` est régénéré depuis la matrice.

## 23. Affichage (`npm run audit:ui`)

Chaque page du menu de chaque rôle, à 1440 px clair, 390 px sombre, 390 px en très grand texte, et en néerlandais et anglais. Les constats du premier passage sont corrigés :

- Cases à cocher : une case garde 24 px partout (formulaires, tableaux, choix de type, invitations) ; un consentement d'inscription est une case avec sa phrase, plus un champ étiré sous un libellé.
- Requêtes refusées : l'agenda ne sonde la couche « Échéances » que pour un club ; les Réglages ne demandent les membres et la gouvernance que pour un club. Plus de 403 dans la console pour la fédération, l'arbitre et le travailleur fédéral.
- Barres d'outils : un choix segmenté et un menu d'une même ligne ont la même hauteur.
- Provinces des clubs (Transferts) : le nom puis le menu, sans dépasser la ligne.
- Une page dont le script ne rend pas la main est notée « page-hang » au lieu de bloquer tout le passage.

Exceptions motivées (`tests/audit/exceptions.json`) : la phrase d'aide qui liste les variables d'un modèle de document, deux graphiques de nature différente dans Statistiques, deux boutons d'invitation de tournoi dont l'un passe sur deux lignes.

Le mode « relevé » (`AUDIT_RECORD`) est coupé : toute différence fait maintenant échouer la CI.

## Vérification

- `npx vitest run tests/access-matrix.test.ts`
- `npm run audit:access` et `npm run audit:ui` (base de démo), rapport dans `audit-report/`.
