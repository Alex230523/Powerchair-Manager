# Textes juridiques (brouillons)

> Tous ces textes sont des brouillons à faire relire par un juriste avant d'accueillir d'autres clubs. Ils ne constituent pas un avis juridique.

## Publics (aussi en pages `/legal/*`)
Écrits depuis `src/domains/legal/texts.ts` par `npx tsx scripts/legal-docs.ts` (une seule source pour les pages et ces fichiers) :
- Conditions d'utilisation : `terms.fr.md`, `terms.nl.md`, `terms.en.md`
- Politique de confidentialité : `privacy.*.md`
- Contrat de sous-traitance (article 28) : `dpa.*.md` ; la version (`DPA_VERSION`) est acceptée par la présidence de chaque club, horodatée, avec l'empreinte du texte ; une nouvelle date redemande l'acceptation.
- Sous-traitants ultérieurs : `subprocessors.*.md`

## Internes
- Registre des activités de traitement (sous-traitant) : `internal/registre.*.md`
- Analyse d'impact pour les données de santé et de mineurs : `internal/aipd.*.md`
- Procédure de violation de données et modèle de notification : `internal/violation.*.md`
